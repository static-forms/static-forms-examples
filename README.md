# StaticForms Examples

Contact form examples for **13 frameworks** using [StaticForms.dev](https://www.staticforms.dev), a form backend for static sites. Each example is a small app you can deploy to Vercel with one click. None of them need a backend.

📖 For step-by-step walkthroughs, read the **[StaticForms blog](https://www.staticforms.dev/blog)**. Each example below links to its tutorial.

Every example has the same form (name, email, message), the same loading/success/error states and the same styling. That makes it easy to compare how each framework handles the same task.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 24 or later (see `.nvmrc`)
- [pnpm](https://pnpm.io/) 10 (`corepack enable` picks up the version pinned in `package.json`)

### Install

```bash
git clone https://github.com/static-forms/static-forms-examples.git
cd static-forms-examples
pnpm install
```

### Configure

1. Create a free account and get your API key at [staticforms.dev](https://www.staticforms.dev).
2. Copy the example env file in the app you want to run and add your key:

```bash
cp apps/next-example/env.example apps/next-example/.env.local
```

Each framework exposes environment variables to the browser differently:

| Framework | Variable | File |
|-----------|----------|------|
| Next.js | `NEXT_PUBLIC_STATICFORMS_API_KEY` | `apps/next-example/.env.local` |
| Nuxt | `NUXT_PUBLIC_STATICFORMS_API_KEY` | `apps/nuxt-example/.env` |
| React | `VITE_STATICFORMS_API_KEY` | `apps/react-example/.env.local` |
| Vue | `VITE_STATICFORMS_API_KEY` | `apps/vue-example/.env.local` |
| SvelteKit | `PUBLIC_STATICFORMS_API_KEY` | `apps/sveltekit-example/.env` |
| Astro | `PUBLIC_STATICFORMS_API_KEY` | `apps/astro-example/.env` |
| Angular | `NG_APP_STATICFORMS_API_KEY` | `apps/angular-example/.env` |
| React Router | `VITE_STATICFORMS_API_KEY` | `apps/react-router-example/.env` |
| SolidStart | `VITE_STATICFORMS_API_KEY` | `apps/solid-start-example/.env` |
| Qwik | `PUBLIC_STATICFORMS_API_KEY` | `apps/qwik-example/.env` |
| Gatsby | `GATSBY_STATICFORMS_API_KEY` | `apps/gatsby-example/.env.development / .env.production` |
| Eleventy | `STATICFORMS_API_KEY` | `apps/eleventy-example/.env` |
| HTML | `STATICFORMS_API_KEY` | `apps/html-example/.env` |

### Run

```bash
pnpm dev               # every example at once
pnpm dev:next          # Next.js on http://localhost:3000
pnpm dev:nuxt          # Nuxt on http://localhost:3001
pnpm dev:react         # React on http://localhost:3002
pnpm dev:vue           # Vue on http://localhost:3003
pnpm dev:sveltekit     # SvelteKit on http://localhost:3004
pnpm dev:astro         # Astro on http://localhost:3005
pnpm dev:angular       # Angular on http://localhost:3006
pnpm dev:react-router  # React Router on http://localhost:3007
pnpm dev:solid-start   # SolidStart on http://localhost:3008
pnpm dev:qwik          # Qwik on http://localhost:3009
pnpm dev:gatsby        # Gatsby on http://localhost:3010
pnpm dev:eleventy      # Eleventy on http://localhost:3011
pnpm dev:html          # HTML on http://localhost:3012
```

### Build

```bash
pnpm build             # builds every example with Turborepo
```

## Deploying to Vercel

Use the **Deploy** buttons in the table above. Each one:

1. Copies this repository into your GitHub account
2. Creates a Vercel project with the **Root Directory** set to that example's folder
3. Asks for that example's API key environment variable

Each app has a `vercel.json` that installs only that app's dependencies (`pnpm install --filter <app>...`), so deploys stay fast even though this is a monorepo.

## The StaticForms API

All examples send a JSON `POST` from the browser:

```javascript
// POST https://api.staticforms.dev/submit
{
  "apiKey": "YOUR_API_KEY",
  "name": "Jane Doe",
  "email": "jane@example.com",
  "message": "Hello!",
  "replyTo": "@",            // reply-to = the sender's email
  "subject": "New Contact Form Submission"
}
```

Responses:

```json
{ "success": true }
{ "success": false, "message": "Error description" }
```

See the [StaticForms documentation](https://www.staticforms.dev/docs) for spam protection (honeypot, reCAPTCHA, Turnstile, ALTCHA), file uploads, redirects, webhooks and integrations.
